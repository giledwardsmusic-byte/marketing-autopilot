# Marketing Autopilot: Single-Folder Content Contract

Primary Google Drive folder: `13V50CtAtjWRZ0H_F9kBbjDdWBdsjxxDE`

## User workflow
The user should only need to manage this one folder. Drop reusable images, videos, PDFs, or marketing copy into it. Marketing Autopilot should discover new items, deduplicate them, import usable assets, and archive generated reusable material back into the same folder.

## Copy Bank
Preferred file name: `Marketing Copy Bank` (Google Doc or Sheet).

Each reusable copy item should carry, where available:
- product
- type: headline | slogan | caption | CTA | description
- text
- destination/link
- tags/platform hints
- approval state

The importer should associate copy with matching products, rotate material, and avoid excessive repetition.

## Generated material
Any reusable asset generated by Marketing Autopilot should be written back to the same Drive folder with a clear name and metadata. Do not create duplicate archive copies.

## Sync safety
Drive read/write sync must use explicit Google authorization. Do not make the folder public as a workaround. Store provider IDs/checksums so repeated syncs are idempotent.
